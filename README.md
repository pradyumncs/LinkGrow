# LinkGrow | Private Encrypted Photo Vault

> **"Your Hidden album isn't actually hidden. LinkGrow is."**

LinkGrow is a modern, high-converting Next.js website and programmatic SEO platform for an encrypted photo vault app, inspired by Vaultaire. It combines local-first cryptographic architecture messaging, an interactive 5×5 pattern lock simulator, and forensic teardown guides.

---

## ⚡ Features

- **Interactive 5×5 Pattern Lock Phone Mockup**: Real-time pattern drawing, SVG line rendering, auto-unlock demo, and vault state transition.
- **Apple-Grade White Theme**: Crisp, responsive typography, subtle grids, and Tailwind CSS v4 styling.
- **The 10 Core Security Pillars**:
  - 5×5 Pattern Encryption (PBKDF2-HMAC-SHA512 with 600,000 rounds)
  - Secret Recovery Phrase (9-word access envelope)
  - Plausible Deniability (Multi-vault architecture)
  - Hidden Isolated Vaults
  - Duress Panic Mode (Silent local index scrubber)
  - Encrypted CloudKit Backup (Zero cloud plaintext)
  - Secure Ephemeral Sharing
  - Cross-Device Encrypted Sync
  - Secure In-App Direct Camera
  - Camouflage Utility App Icons
- **Forensic Teardowns & Security Guides**:
  - *Are Hidden Photos Saved to iCloud? What Apple Doesn't Tell You*
  - *Why Fake Calculator Photo Vault Apps Are Dangerous in 2026*
  - *AES-256-GCM vs Standard Encryption: Why Math Matters More Than Passcodes*
  - *Trading In or Selling Your iPhone? How to Ensure Private Photos Can Never Be Recovered*
  - *Apple Intelligence & On-Device Photo Scanning: Is Your Private Album Really Safe?*
- **SEO & Generative Engine Optimization (GEO)**:
  - Full `SoftwareApplication`, `FAQPage`, and `Article` JSON-LD schemas.
  - Custom `robots.txt` explicitly whitelisting AI search bots (`GPTBot`, `ClaudeBot`, `PerplexityBot`, `Google-Extended`, `OAI-SearchBot`).
  - Dynamic `sitemap.xml` with SSG routes and 32-language internationalization structure.

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the site.

3. **Production build**:
   ```bash
   npm run build
   npm run start
   ```
